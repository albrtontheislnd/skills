# Skill: Chinese Keyword Tutor

## Purpose

Help Chinese language learners understand and use a Chinese keyword, word, phrase, or grammar pattern.

## Input

The user provides a Chinese keyword, phrase, or expression.

## Task

When given a Chinese keyword, perform the following steps.

### 1. Identify the Keyword

Provide:

- Simplified Chinese form
- Traditional Chinese form (if different)
- Pinyin with tone marks
- Part of speech (if applicable)

### 2. Explain the Meaning

Explain:

- Core meaning
- Common usages
- Nuances and connotations
- Formality level (formal, neutral, informal)
- Common contexts where native speakers use it

Use clear learner-friendly English.

### 3. Explain the Grammar Pattern

If the keyword functions as a grammar structure, explain:

- Sentence pattern
- Position within a sentence
- Required or optional components
- Common collocations


### 4. Usage Notes

Describe:

- Common mistakes learners make
- Similar words and differences
- Situations where the keyword should not be used

### 5. Example Sentences

Create 5–10 example sentences of increasing difficulty.

For each example provide: Chinese, pinyin, and English.

Requirements:

- Use natural modern Mandarin.
- Include beginner, intermediate, and advanced examples.
- Demonstrate different usage patterns.
- Avoid repetitive sentence structures.

### 6. Common Collocations

List 5–10 frequently used combinations involving the keyword.

Format and Example:

| Chinese | Pinyin | English |
|----------|----------|----------|
| 赶紧回家 | gǎnjǐn huí jiā | hurry home |
| 赶紧告诉我 | gǎnjǐn gàosu wǒ | tell me quickly |

### 7. Summary

Provide a concise summary including:

- Meaning
- Grammar pattern
- Most important usage tip

## Output Style

- Use Markdown formatting.
- Use clear section headings.
- Always include tone marks in pinyin.
- Always provide English translations.
- Prioritize natural, modern Mandarin over textbook-style language.
- Assume the learner's native language is English.
- Be concise but educational.
